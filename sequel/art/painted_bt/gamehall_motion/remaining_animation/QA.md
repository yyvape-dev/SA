# T4 遊技場の残存アニメーション

承認済み原画の表示用ラスターを使用した。3200×2000座標で登録し、PNGアトラスには各部品を等倍で収録した。輪郭を個別にトレースし、可視部のRGBAは機械的に抽出した。動作で露出する人物の下地に限り、近傍画素で補完した。

| 対象 | 判定 | 内容 |
|---|---|---|
| ディーラー | PASS | 中央卓の1名。頭、胴、左右の腕と手を8パーツに分離。盤面操作をGodotで再生。カード配布の独立アニメは未制作 |
| ゲーム中の客 | PASS | 卓の左右に2名ずつ、右の筐体脇に1名。計5名を個別抽出。頭部の振り、手元を上げる反応、フェルトへ手を出す動きを再生。奥の群衆は遠景として扱った |
| スロット | PASS | 既存実装の対象に合わせ、左右の最前列の外側筐体2台。筐体、表示枠、3列のリール、ランプ、ボタンを各7パーツに分離。リールの送りと段階停止、ランプ発光、ボタン押下時の暗転を再生。奥・内側の筐体は静止画 |
| ルーレット | FAIL | 卓の台座とフェルトを2パーツに分離。承認済み原画でホイール、ポケット環、球の輪郭を判別できなかったため、その3要素の抽出と回転・減速・停止は未達。フェルト上の駒をルーレットの球として扱わなかった |
| 製品シーンへの常設・Web・実機 | NOT TESTED | Godotの実ゲーム内で撮影用に配置した素材納品。製品側の再生コードは今回の検証対象外 |

- `*_cutout.png` は元絵の同座標から取った静止再合成。`*_parts.png` は透過パーツアトラス、`*_masks.png` は同じ座標でのマスク。`rig_manifest.json` に画像内座標、回転中心、親子と描画順を記録。
- 9対象すべてで、アトラスから静止再合成したRGBAは切り出しと完全一致。全可視画素のRGBAを承認原画の同座標と比較した。
- `motion_frames_00.png` から `motion_frames_03.png` は透過の差分フレームアトラス。36フレーム・12fps。ベース原画へ `overlay_origin_px` を起点に重ねる。先頭と末尾のフレームは透明。
- `d2_full.mp4` と `d2_detail.png` は、実ゲームで遊技場へ遷移後、Godot 4.7.2、GL Compatibility、D2（1688×780）で納品用アトラスを再生・撮影したもの。静止素材と可動素材の位置合わせ、動き、前景との重なりを確認した。
- `parts_contact.png` で9対象の静止再合成を一覧できる。
