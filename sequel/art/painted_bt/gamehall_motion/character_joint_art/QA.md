承認済み原画から切り出した3名の素材。対象ブランチは `test/sa2-t4-gamehall-relayout-20261109`。素材の来歴は [既存マニフェスト](../motion_manifest.json) と各 `rig.json` に記録した。

| 人物 | パーツ数 | テストした可動部位 | 固定・遮蔽 |
|---|---:|---|---|
| `cloaked_man` | 4 | フード付き頭部、右肩、右肘 | 左腕、右手首、胴・裾・脚。右手は輪郭が衣装と一体 |
| `left_woman` | 4 | 頭髪込みの頭部、左肩、左肘 | 左手を前腕に含めた。右腕の遮蔽部、胴・スカート・脚を固定 |
| `right_woman` | 5 | 頭髪込みの頭部、右肩、右肘、右手首 | 左腕の遮蔽部、胴・スカート・脚を固定 |

## 座標と画素

- `cutout.png`、`parts/*.png`、`masks/*.png`、`review/rest_recomposition.png` は元の3200×2000座標系。左上原点で境界の右端・下端は排他的。縮尺、足裏および骨盤の基準を固定した。
- `rig.json` の `parts` は親、回転中心、描画順序、境界、試験角度を記録する。原寸PNGからテクスチャを切り出す場合は `bbox_xyxy` の左上を差し引いてローカル座標に変換できる。
- 人物ごとに個別に輪郭をトレースし、可視画素の所有マスクを重複なく分けた。関節境界の数画素は元の袖の所属に合わせて調整し、正確な境界はPNGマスクに記録した。可視な完全不透明のソースRGBの編集は0画素。左の女性の裾231画素は旧レイヤーの透過フェードに重なったため、承認済み全景の同座標RGBを使用した。全景は来歴に記載の原画を既存のLanczos拡大と下端合わせで3200×2000にしたもの。
- 隠れた継ぎ目に限り、隣接する親パーツの元画素を複製した。領域は `*_hidden_fill.png` に分離し、静止時に子パーツで覆われる。補完画素は男性1,959、左928、右1,319。隠れている腕・手や細かな指は描き足していない。
- `review/rest_on_approved_source.png` は `source_crop_xyxy` と同じ画角で原画に重ねた検査画像。ほかに2倍比較、原寸パーツ一覧、静止〜ピークのコンタクトシート、単体GIF、実Godotの等倍切り出しとGIFを収録。

## QA

| ゲート | 判定 | 確認内容 |
|---|---|---|
| 1. 3名の単体抽出 | PASS | 原寸、2倍拡大、暗色・明色背景、実表示で輪郭を確認 |
| 2. 可視部のRGB・比率 | PASS | 完全不透明の入力RGBの編集0。左の裾の旧透過端は同じ全景の画素で回復。全て位置・比率固定 |
| 3. 家具・床・別人物 | PASS | 3名とも背景物の形状と床の影を除去。左の指先など低解像度で背景光と接する境界は元絵に焼き込まれた混色が残り得る |
| 4. 関節位置 | PASS | 原画で判別できる首・肩・肘、右の女性の手首を採用。遮蔽部を可動対象から除外 |
| 5. 静止再合成 | PASS | 3名とも単体PNGと静止再合成の全RGBAが一致。承認原画との位置合わせを比較で確認 |
| 6. 可動時の継ぎ目 | PASS | 3名×32フレーム。試験角度内でアルファ128基準の閉じた穴0画素。足元固定、原寸とD2で関節を確認 |
| 7. PNG・マスク・JSON・プレビュー | PASS | 3名の単体PNG、全13パーツ、マスク、座標、比較、再合成、アニメーションを個別に収録 |
| 8. GitHub反映・再取得 | コミットの納品報告に記載 | コミット前のローカル画像検査とは別に照合 |

Godot 4.7.2、GL Compatibility、D2の実画面1688×780で試験。既存の遊技場を開いた後、撮影時だけ試験背景と回転するSprite3Dの親子階層を配置した。既存背景には人物が焼き込まれているため、試験背景の人物直下だけを補った。試験背景を製品の背景として扱わない。GIFは32時点、1.92秒のループ。GIFのフレームは実撮影の該当箇所をリサイズなしで切り出した。

製品シーンへの組み込み、実機・Web書き出し、試験角度を超える動作は NOT TESTED。収録したPNG・座標は背景人物の小さな動作用。
