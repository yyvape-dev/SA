## 守ること（ユーザーの決まり）
- 色：青＝味方、赤＝敵、金＝物資（お金・装備）・決着。
- 戦闘画面に技名・敵の数の文字は出さない（数字は出す）。
- 絵は縮めない・崩さない。
- 押す所は 44px 以上（844×390 の時）。右下は攻撃・技のボタン、左下は移動のスティック、右上は小さな地図・必殺技。
- UI の日本語は抜き出しのフォント `assets/event_idle/sa2_t6_ja.otf`。新しい字は `tools/extend_ja_font.py` で足す。
- お手本はアラド戦記（クリア後はボス部屋で拾える → もう一度・別のダンジョン・街へ戻る、店は売ると持ち物が開く）。
