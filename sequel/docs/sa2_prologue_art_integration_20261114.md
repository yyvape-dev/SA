- 机と照明器：別スプライトで配置。机の前後にラナが回れる。客室の調べる紙は既存の独立した表示を維持。照明器は机上の高さ0.95mに配置して寄りで表示する。
- 台本・進行・専用保存形式は変更していない。本編起動・既存Web成果物・mainは変更していない。

## 原画と加工の記録

原画JPEG8枚は無変更。ゲーム用は `assets/prologue/*.png`、出典SHA256・寸法・輪郭範囲・明示した穴の座標は `assets/prologue/provenance.json`。

| 原画 | 元寸法＝ゲーム用PNG寸法 | PNGの状態 |
|---|---|---|
| office / guest_room / audience_room | 各1536×864 | RGB、JPEGの復号画素をそのままPNG保存 |
| desk | 1536×1024 | RGBA、白背景のみ除去 |
| portable_lamp | 1254×1254 | RGBA、外周と取っ手の穴を除去、ガラスは不透明で保持 |
| sera_book | 702×1536 | RGBA、白い服は保持 |
| mina_bread | 672×1536 | RGBA、白い服とパンの布は保持 |
| imperial_envoy | 1024×1536 | RGBA、白いシャツ・封書は保持 |

`tools/import_prologue_art.py` は近白色の外周連結領域だけを背景とし、ランタンの取っ手内側は明示した座標(620,160)から抜く。衣装・ガラス内部の白を一律に透明化しない。原画の再生成・原寸変更はしていない。出力PNGのRGBはJPEG復号値と一致し、透過対象でアルファだけを変更する。

Godotでは原寸・可逆取り込み（compress/mode=0、size_limit=0）。新規PNGにmipmapを付け、縮小表示時の細線のちらつきを抑えた。原画やゲーム用PNGの寸法は落としていない。ラナ・リリィの既存アトラス設定は維持。

再現：`python3 sequel/tools/import_prologue_art.py`（Pillow / numpy / scipy）。既存の `.png.import` を同梱しているため、新規PNGも同じ可逆・mipmap設定で取り込める。

## 検証結果

- **PASS**：8枚の寸法、アルファ有無、出典／出力SHA256、原画無変更。別レビューでも一致を確認。
- **PASS**：`python3 -m unittest discover -s sequel/tests -p test_prologue_art.py`。外周の白と白い衣装の区別、明示した穴、実原画のセラ／ミナの白い衣装と照明器のガラスの保持（2テスト）。
- **PASS**：専用状態・シーン接続と既存会話UI／T1進行、合計5本のGodotテスト。シーン接続テストは仮人形が提供絵へ差し替わったことも確認。
- **PASS**：Godot **4.6.3**、OpenGL Compatibility、Mesa llvmpipe。1280×720／1560×720で全11状態（22枚）、机の前後を各比率で4枚、合計26枚。足元・縮尺・机の前後関係・照明器・会話表示を確認。照明器の最初の撮影で机から浮いていた配置は0.95mへ下げ、更新した撮影で接地を確認した。
- **PASS**：別コンテキストのコード／原画レビュー。重要な回帰の指摘なし。初期撮影のランタン接地、実原画のアルファ確認、机の前後の描画確認はその後実施済み。
- **NOT TESTED**：指定Godot4.7.2、Web書き出し、ブラウザ、iPhone。この環境は4.6.3のみ。既存4.7.2用パックとは混ぜていない。

軽微な継続事項：スプライト作成時の輪郭範囲は現在取り込んだテクスチャから測っている。由来JSONの範囲を再利用する最適化は行っていない（性能問題は未確認）。背景の下端より下は画面下の操作領域の地色になる。入室・退出の細かなアニメーション、視線差分、Web用の専用配信単位は引き続き次工程。
