# SA2 T6 引き継ぎ

## 出発点

- リポジトリは `yyvape-dev/SA`、Godot 4.7.2、対象は `sequel/`。T5の作業先は `test/sa2-t5-training-dialogue-20261110`。次チャットでは先頭を取得し、`main`（T5背景統合時点は `3a0a462`）との差分を確認する。T6の変更はT5先頭から切った別ブランチへ。
- 起動シーンは `sequel/sa2_t5_training_preview.tscn`。受付への移動 → 暗転 → 会話専用カメラとラナ・リリィの待機 → 暗転 → リリィの演習。イベント待機素材は `assets/event_idle/`、台詞は `dialogues/ja/C1-06-t5-preview.json`。教官は既存NPCの仮配置。
- iPhoneで通しプレイと負荷感がユーザー確認済みなのは、旧背景の `9f3dfd6` 版。現行「裏の町」の背景を使う版は別ビルドとして扱い、実機確認結果を混同しない。
- 実機確認先は https://sa2-npc-device-check-20261110.mintybeam1.chatgpt.site/t5/ 。配信版はページの `sourceBuild` をコミットと照合する。

## T6の最初の到達点

1. ラナの通常戦闘画面とリリィの演習を横画面で並べ、左ドラッグ移動、攻撃の押し／離し、回避／防御の位置と入力反応を比較する。
2. `scripts/touch_ui.gd` の共通操作UIを再利用し、リリィには `scripts/sa2_t2_lily_manual.gd` の操作へ渡す。現状の演習専用四角ボタンとタッチ移動を同時に生かすと二重入力になるので、切り替え時に入力担当を一つにする。
3. 共通UIはラナのスキル枠、必殺技、設定、クールダウン情報も参照する。リリィに対応する機能だけ表示し、ラナ専用の状態を読ませない。リリィの回避／防御タイミングと各キャラの技は維持する。
4. HUDはHP・スキルなどプレイ画面に重ねる表示。既存VFXを使って敵の予兆、ヒット、回避／防御の成立が読めるかを確認し、不足だけを具体的に記録する。
5. 横16:9とiPhone相当の横長比率で、会話中の操作ロック、演習開始時の入力復帰、攻撃押し／離し、回避／防御、勝敗・復帰、ラナ側の回帰を確認する。Godot実画面とiPhone実機結果は別記録。実機未接続の場合は未検証とする。

## 関連箇所

- `scripts/sa2_t2_playable.gd` — 会話、演習、仮タッチUIの寿命管理。
- `scripts/touch_ui.gd` — ラナのタッチUI、入力受付、スキル表示。
- `scripts/sa2_t2_lily_manual.gd` — リリィの移動・攻撃・回避／防御。
- `tests/sa2_t5_training_preview_test.gd`、`tests/sa2_t2_5_input_test.gd`、`tests/sa2_t2_5_recovery_test.gd` — 通し・入力・復帰。Godot 4.7.2 の `--headless --path sequel --fixed-fps 60 --script res://tests/…` で実行。
