# SA2 スキルツリーの読みやすさ（2026-11-15）

今回の依頼「デザイン、わかりやすさや説明を一気に進めて」に基づき、既存の技ごとの枝・3人のタブ・街での育成を維持して改善する。ソースの基点は `46d2741`。ダンジョン選択と戦闘HUDは完成済みであり、変更対象ではない。

## 方針

既存の四行ツリーを残し、右に選んだ技の説明と操作を置く。採用済みの肖像・戦闘用スキル画像、真鍮・暗いガラス・青い選択光を再利用する。新しい絵の生成はしない。技名・役割・派生の効果を日本語で説明し、日本語フォントの不足文字を補う。

小改修で名前だけ足す方式は、誤タップでSPを消費する問題が残る。全画面カード一覧への変更は採用済みの「技ごとの枝」を失う。既存ツリー＋詳細欄なら、枝の関係を残したまま判断して育成できるため、この方式を選ぶ（実装側の判断）。

## 操作

- 技・派生を押す操作は選択と説明の確認のみ。SPを使うのは別の「強化 1 SP」ボタン。
- 詳細欄に現在→次レベルの威力倍率とCD／必殺消費を実際の技テーブルから表示。倍率は同じ派生のLv1を100%とする。
- 派生はLv3以上・SP不要・同時に1つ。選んだ候補の説明を読んで適用し、適用中の候補は元の技に戻す操作として示す。
- SP不足・最大レベル・未解放・必殺派生の未実装を、押せない理由として表示する。
- 振り直しは選択中の1人だけが対象。返却SPを示し、既存の二段階確認を読み取れる文章にする。
- SP獲得条件、仲間の自動戦闘にも反映、閉じると保存、街でのみ変更可能を短く案内する。

## 制約と確認

成長・戦闘・派生patch・セーブ形式・パーティのルールは変更しない。必殺派生は未承認なので中身を追加しない。ツリーの日本語は `specs/skill_tree.md` に基づく。戦闘・遠征盤の数字のみという決まりは維持する。

Godot公式4.7.2で、SP0／Lv2→3／Lv5／3人／未実装必殺／振り直し／保存復元を検証。844×390と1280×720で描画とタッチ矩形を確認し、既存HUD・遠征盤テストを回帰確認する。過去の実機結果は今回の検証に数えない。
