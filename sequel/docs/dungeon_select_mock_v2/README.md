# ダンジョン選択 v2：地図の情報枠＋選択後の流れ（モック）

ユーザー指摘: 前回の選択後UI/UXは未完。地図にアラド戦記のような最低レベルと敵の小枠が欲しい。

ユーザー確認済み: レベルは**推奨値**。レベル不足による入場制限は設けない。

## 見る物

- `index.html`: 画像を埋め込んだ単一HTML。ダウンロードしてブラウザーで開ける、操作可能な検討用モック。ゲーム本体には反映しない。
- 地図で入口／敵の小枠→難易度→人のボタン→仲間→扉のボタン→待機。上のタブでも各画面へ移動できる。
- [地図](01_map.png) / [難易度](02_difficulty.png) / [仲間](03_party.png) / [待機](04_loading.png)。各844×390。

## 提案（採用未決）

1. 地図の4地点に敵の小枠91×62pxと推奨レベル。建物は行き先、敵はそこで何と戦うかを伝える。入口と小枠は同じ選択先。
2. 現在のラナのレベルを右上。推奨値が高い場所は数字だけ橙色。鍵とは結び付けず、入場は可能。進行による未開放は従来どおり別条件。
3. ダンジョン選択後は左を敵の大きな姿＋入口＋推奨レベル＋難易度に固定。右側のみ難易度から仲間へ切り替え、行き先を見失わない。
4. 難易度の次は「人＋矢印」、最後の入場は「扉＋矢印」。同じ三角の連続をやめ、次に何が起きるかを絵で区別する。
5. 仲間はラナ・リリィ・ランカを大きく、将来2枠を小さく。金の固定、青の選択、チェック、人数の数字を併用。
6. 待機でも同じ敵・入口・難易度・編成を引き継ぎ、押下が受理されたと伝える。進捗不明のときは回転印と不定進捗。モックの動きは例であり実通信ではない。

比較した構成: 地図の上に難易度と仲間を1枚でまとめる案なら1操作減るが、844×390では敵絵・3難易度・3仲間＋将来2枠が競合する。今回の提案は2段階を維持し、左の情報を固定する。別の巨大な確認ダイアログは挟まない。

## 事実／仮置き／未決

**事実:** 既存の背景・入口4枚・敵スプライト・採用済み顔絵をそのままHTMLで参照。新しい敵やキャラの絵は生成していない。敵は t1b / t2e1 / t3e1 / hr の既存歩行1コマを使用。敵の小枠はボス固定ではなく各地点の代表敵として仮配置。ゲーム画面内は数字・記号のみ。

**仮置き:** 推奨レベル4/10/18/26、ラナ12、最速02:38はレイアウトを見るための例で、ゲームの値ではない。推奨レベルは現行dungeon_themes.gdに存在しないため新しい実データの設計が必要。

**未決:** 実際の推奨値、通常敵／ボスのどの絵を各枠の代表にするか、レベル不足の橙色表示を採用するか。このモックの構成そのものも未採用。

難易度変更で上限人数が減っても、選んだ仲間を黙って外さない。編成で人数を調整してから入場する扱い。実装する場合は人数超過時の人数表示・該当札の揺れなどを詰める。

## 確認範囲

Chromium 844×390の画面を撮影し、入口→難易度→仲間→待機、仲間切替、推奨レベル未満の地点も選べること、pageerrorなしを確認。HTMLは検討用で、Godotの入力・通信・セーブとは接続していない。実機遅延やGodot上の見え方の検証結果ではない。

本体のscripts/、現行試し版、mainには変更なし。ソース作業ブランチに資料として保存する。

## 画像生成による仕上げ案

[生成モック4画面](mock_board_generated.png)。OpenAI image_gen、元のmock_board.pngを参照画像として使用。配置・情報・キャラの同一性を維持し、黒鉄・青いエナメル・古い金の縁取り、選択の光、カードとボタンの材質を仕上げる指示。文字なし、数字と記号のみ、推奨レベルは制限に使わない条件を指定。

これは未採用の美術モック。生成によって背景やキャラの細部が変化しているため、そのまま本番素材へ置き換えない。実装する場合は採用済み原画を保ち、枠・背景処理・記号のデザインを再現する。タッチサイズ・文字の可読性・挙動は画像だけでは検証できない。元画像は変更せず保存。

## ウインドウ構成からの再設計案（画像生成・未採用）

ユーザー指示: 菱形・ドアなどコードで描いた仮記号の見た目をやめ、各ウインドウの設計から世界観に合わせて画像生成に考えさせる。

[世界観から再設計した4画面](mock_board_world_design.png)。OpenAI image_gen。参照は前案mock_board_generated.pngと世界観原画concept_01.png。world_concept.mdを読み直し、裏町の魔法＋技術・鋼の足場・多色の魔導光・危険な門の設定を指示に反映。

意匠案「裏町の探索者の魔導式遠征盤」: 革・黒い布・再利用した真鍮・魔導管・現場の絵の札を組み合わせる。これは新しい世界設定の確定ではなく、UIの造形提案。

- 地図: 敵と推奨値を載せた小さな調査札、物理的な留め具・封蝋、光る経路。
- 難易度: 抽象的な菱形の数ではなく、青い路地／赤い待ち伏せ／赤金の激戦という3枚の現場絵で危険度を比較。人数は小さな肖像枠＋数字、記録は実物の懐中時計風。
- 編成: 行き先と危険度を左の札にまとめ、仲間の肖像を盤面へ装着。ラナ金、仲間青。将来2枠は鎖で閉じた肖像マウント。
- 出発: ドアや矢印の平面アイコンを使わず、押して起動する金の魔導装置。
- 待機: 同じ装置の通電として、円形の観測レンズ・選んだ肖像・光の流れる管で入場のつながりを表現。

確認した見た目: 4段階、3難易度、3人＋将来2枠、推奨値4/10/18/26、現在12の構成を保持。従来の菱形難易度・ドア記号・人型記号・チェックの列を置き換えた。数字は引き続き仮。装飾の多さ・押せる場所の判別・844×390での可読性は未評価。生成画像はキャラや背景の細部を変更するため、原画の代替としての採用はしない。

本体への反映なし。前案も残して比較できるようにする。
