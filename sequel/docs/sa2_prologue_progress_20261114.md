## 今回追加したもの

`sa2_prologue_preview.tscn` を独立起動する。執務室の朝→ミナのパン→リリィへ歩いて話す→客室へ→机を調べる→書き置きの拡大→約束の会話→三日後→使節と招待状→照明器への寄り→渡航決定→章題まで接続した。

ラナ・リリィは現行イベント待機アトラスを原寸・既存縮尺で使用。背景3室・机・紙・パン・封書・照明器はコードの仮形状。ミナ・セラ・使節は「仮」と明記した人形。新規画像生成はしていない。

外部JSON8本を既存DB・会話パネルへ接続した。[台本一覧](sa2_prologue_script_20261114.md)は引用／補筆を行単位で区別する。承認済み原稿全文の復元ではなく、接続文を含む実装用台本。紙の文面もJSONから表示する。ランカの行先、真相、大公の刑は追加していない。

## 起動と操作

本編の起動シーン、既存プレビュー、Web成果物は変更していない。

```bash
godot --path sequel res://sa2_prologue_preview.tscn
```

- 左右キー／A・D（上下キー／W・Sで帯の奥行き）、画面左側のドラッグまたは左右ボタンで移動。
- 相手や机のそばで右下の文脈ボタン。E／Enter／Spaceでも操作。
- 会話は既存の全文送り・自動・ログ・確認付きスキップ。スキップは現在の会話単位で、調査や別場面を飛ばさない。
- 「最初から」は確認付き。確認中は会話の自動送りも停止する。

保存は `user://sa2_prologue_preview_v1.json` のみ。場面beat、行ID、ラナの位置・向きを保存し、発見済み・完了はbeatから導出する。`ending` が第一章へ渡せる完了状態。本編への自動遷移は未接続。成長や訓練のセーブは変更しない。

会話行が変わる時・操作確定時・移動中0.5秒ごと・フォーカスが外れる時に保存。tempファイル→renameで更新。場面の確定配置を先に保存し、暗転中に閉じても次回は確定配置へ戻る。保存失敗は画面に表示。破損した保存は状態を途中適用せず拒否する。
