# 仕様：リリィの攻撃の軌跡とエフェクト（2026-11-06 22:40 ユーザー承認）

実装する人（Claude Code・チャット）はこれを読んでから作る。終わったら `sequel/HANDOFF.md` に結果（事実と数値）を書く。
手順・撮影・書き出しは Skill `sa2-godot-check`、技の作り方の型は Skill `sa2-skill-craft`。

## 背景（ユーザーの判定）
- ラナの攻撃の見た目は良い。リリィは地味。
- アクションゲームの基本は「見た目より広い攻撃範囲」「大げさなくらい派手なエフェクト」「キャラごとの色づかい」。今のリリィは控えめ。
- 事実：リリィの当たりの距離は約 1.2〜1.4m（`tools/pack_lily.py` で測った値。ラナは 2.5〜3.2m）。斬撃の帯は技に関係なく同じ小さな弧（`ally.gd` の slash の spec）。

## 決まり
1. **軌跡は足の通り道をなぞる**：連番の各コマから「つま先（攻撃の先端）」の位置を自動で測り、当たりの前後のコマの点をつないで光の帯（リボン）にする。決まった形の弧は使わない。
2. **誇張**：軌跡の太さは脚の太さの2〜3倍、長さは実際の通り道の 1.3 倍（足元の原点から外へ伸ばす）。当たりは軌跡の外側まで届く（見た目より少し広い）。目安：前へ 2.0〜2.6m、奥行き ±1.0m。
3. **色＝白銀の軌跡に蒼い稲妻**（ユーザー：「青い稲妻」でも「白銀と稲妻」でも可 → 髪の白銀に合わせてこれに決定）。
   - 帯の芯：白（#FFFFFF）、本体：白銀（#D8E4F0）、外側のにじみ：蒼（#4FB8FF）。縁にごく淡い紫（#9A8CFF、量は少し）。
   - 帯の縁に細い稲妻のひび（ノイズで折れ線、明滅）。当たった所で稲妻が弾ける（短い折れ線の放射＋粒）。
   - ラナ＝金（動画に焼き込まれた金の軌跡）。リリィ＝白銀＋蒼雷。決まりの「青＝味方」の範囲で、一目で区別できる。
4. **3段で見せる**：溜め（つま先に蒼い光が集まる、0.1〜0.15秒）→ 頂点（太い帯＋大きな閃光）→ 余韻（帯が稲妻の粒になって散る。すぐ消さない、0.3〜0.5秒）。
5. **画面の揺れ・衝撃波（`fx.shockwave`）は最後の当たりと大技だけ**。全部に入れると効かなくなる。
6. 文字（技名）は出さない。数字は出す。

## 5本の技（`ally.gd` の PATTERNS。12コマ単位の当たりは `assets/lily/lily.json`）
| 技 | 軌跡 | 当たり方・移動 |
|---|---|---|
| atk_jabkick（突き→上段） | 突き＝まっすぐな短い光の槍。上段＝縦の三日月 | 2段。2発目は少し浮かせる |
| atk_highkick（上段蹴り） | 縦に高い三日月＋稲妻のひび | 浮かせる |
| atk_roundhouse（回し蹴り） | 床と平行の大きな弧（半周以上） | 前後の両側に当たる（side 0）。大きく吹き飛ばす |
| atk_heeldrop（かかと落とし） | 振り上げ＝細い弧。振り下ろし＝太い光の柱 → 床に稲妻のひび＋衝撃波＋砂煙 | 最後の当たりは足元の円の範囲（半径 2.2m 目安）。締めの大技（後で方式C＝Godot の Forward+ で焼いた連番に差し替える第一候補） |
| atk_rush（飛び蹴り） | 体の残像3体（蒼く透ける）＋足の後ろに長い光の槍 | 実際に 3〜4m 前へ進む。通り道の敵を全部貫く（帯の当たり） |

- 「浮かせる」は今の敵に空中の状態が無いので、まずは強めののけぞり＋絵を少し持ち上げる（sprite.position.y）で表す。本格的な空中の状態は別の作業。

## 作り方（案。もっと良い方法があれば提案してから）
1. つま先の点：`tools/pack_lily.py` で、攻撃のコマごとに「足元から見て、前へいちばん遠い不透明の点」（上段・かかと落としの振り上げは上へ遠い点も候補）を測り、`lily.json` の clip に `tip: [[x, y], …]`（m、足元原点、右向き）で書く。外れる技は今の HITS と同じように手で指定できるようにする。
2. 帯：`fx.gd` に `ribbon(points, face, spec)`（点の列から太さ付きの帯のメッシュ。太さは中央で最大・両端で細る）を足す。`fx_add.gdshader` の mode 0（流れる模様・溶け消え）を使い、色は上の白銀・蒼。稲妻のひびは同じシェーダーに mode を足すか、別の細い帯を重ねる。下に暗い層（`fx_dark`）を敷く（夜の画面で沈まないように）。
3. 当たり：`battle._attack_from` の spec に `shape`（"fwd"＝今の前方、"both"＝両側、"circle"＝足元の円、"band"＝通り道の帯）を足す。距離はつま先の点の最大値×1.3＋0.3m。
4. 移動：atk_rush は当たりまでの間に 3〜4m 進める（`ally.gd` の atk の中で position.x を進める。前進の量は連番の dx を差し引く）。
5. 比較：`main._capture_fx`（CAPTURE_FX）に「リリィの5本の頂点」の場面を足し、`FX_OLD=1`（今の見た目）と並べる。iPhone の URL も添える。
6. 注意：攻撃の速さは今 `SPD` 4.0（1本 0.8〜1.3 秒）。溜め・余韻の秒数はこれに合わせて短めでよいが、余韻だけは攻撃が終わっても残す。
7. Web（Compatibility）では粒の尾・デカールは使えない。帯はメッシュ＋シェーダーで作る。
