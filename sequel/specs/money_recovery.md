# お金と回復 仕様（②）

2026-11-16 作成（Claude）。検討表 https://claude.ai/artifact/7SXNn7Xi1yTFrCEpVipjbC の「お金と回復」「ドロップ」「敵」の案と、ユーザーの決定。数値は `scripts/economy.gd`・`scripts/foe_stats.gd`・`scripts/dungeon_themes.gd`。「仮」は Claude が決めたもの。

## 1. ユーザーの決定（2026-11-16）
- 店：**裏の町の屋台**（水晶の屋台＝薬屋、`BT.STALLS` の stall_crystal に近づくと開く）と、**ダンジョンをクリアした後**。アラド風に、結果の画面を閉じた後もボス部屋で少し動ける（金の扉＝店、紫の扉＝街へ）。
- 回復のボタン：ユーザー「左上押せるか…？一般的なスマホゲーの UI を参考に」→ 参考の事実：Diablo Immortal は回復薬が画面の右側・技のボタンの上にあり、使った後に短い待ちがある。SA2 は右側が必殺技・コンボ表示・技で埋まっているので、**左上（体力・仲間の帯の下）**に置いた（ボタンはスティックより先に判定される）。キーボードは H。
- 倒れた時：**「立ち直る（金額）／あきらめる」を選ぶ**。1 周 1 回、100G×テーマの倍率。
- 経験値：**雑魚 1 体の経験値を 2 倍（敵の数を半分にした分）＋敵の種類ごとの倍率**（検討表「敵」の経験値の倍率）。

## 2. お金
- 雑魚：種類ごとの額（検討表「敵」）×テーマの倍率（T1 1・T2 1.5・T3 2.2・T4 3＝テーマの xp）×難易度（ノーマル 1・ハード 1.5・エキスパート 2）。床に金の硬貨。触れるか 1.4m 以内で寄ってくる（仮）。部屋を片付けると残りはラナへ集まる（仮）、部屋を出ると拾ったことに（仮）。
- ボス：検討表の額（鉄腕支配人 50〜80・馬型の機兵 100〜150）、雑魚の絵のボス（T2・T3）は 50〜80（仮）。6 枚に分けて散らす（仮）。宝箱は③で。
- 結果の画面に得たお金（立ち直りに払った分を引いた差）。失敗・戻る扉は入る前へ戻る（お金も、使った回復薬も戻る）。
- 自動の周回（2026-11-16）：T1 ノーマル 1 周 +190G（31 体＋ボス）、T2 ノーマル +391G、T1 ハード +422G。検討表の目安は T1 ノーマル約 160G。

## 3. 回復
- 回復薬（小）体力 30%・40G・持てる 5、（大）70%・120G・持てる 2。ボタン 1 つで小→大の順、使った後 3 秒は使えない。体力が満タンの時は使わない。はじめに小 2 個（仮）。
- 雑魚が小を 3% で落とす（持ちきれない時は 20G、仮）。
- 部屋を片付けた時 体力 10%。ボスの扉の前の回復は無し。
- 立ち直る：体力を全部戻し、2 秒当たらない（仮）。

## 4. 確かめ方
- 撮影 `TOWN=back CAPTURE_SHOP=1`：薬屋 → 買う → ダンジョンの回復薬のボタンとお金 → 倒れて立ち直る → 結果 → クリアの後に動ける所と店。captures/shop_*.png。
- 自動の周回（DUNGEON_TEST）の要約に「お金 前→後」。自動の周回は立ち直りを選ばず、クリアの後もすぐ街へ（今どおり）。
