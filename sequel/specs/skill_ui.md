# スキルの導入（縦切り）— 2026-11-07 チャットで決定

ユーザー決定の元：右下に操作を集約・常時表示は3〜4個・戦闘前にスロットへセット・ボタンは今より少し上げ半透明で細縁・CD は外周リング。大量スキルの長押しリングとフリック派生は「将来」。
**この縦切りの範囲**：常時3枠＋外周リングのCD＋街でのスロット設定＋技3つ。長押しリング・フリック派生・4枠目は作らない（枠の位置だけ空けておく）。
UI の文字は使ってよい（2026-11-07 ユーザー：「文字は出さない」は前作の演出の決まりで UI とは別）。ただし日本語フォントが入るまでは、数字と図形で足りる所は数字と図形。

## 1. 右下の操作（`touch_ui.gd`）
単位 u = 画面の高さ/720。今より全体を約 40u 上げる（iPhone のホームバーと親指の付け根を避ける）。
- 攻撃：中心 (W−175u, H−190u)、半径 78u（今は (W−170, H−150)・82）。
- 回避：中心 (W−345u, H−105u)、半径 50u。
- スキル3枠：攻撃の中心から半径 175u の弧の上、角度（右＝0°、上へ反時計回り）165°・115°・65°、半径 52u。左から枠1・2・3。
- 4枠目（今は描かない）：角度 215° を空けておく。
- 見た目：地は暗い紺 α0.28（押している間 0.55）、縁は細い 2u（白 α0.5、攻撃だけ金 #c9a24a、回避は今の水色）。モックの不透明・太い金縁にはしない。アイコンは今と同じくコードの図形（技が固まったら外部AIに発注票）。
- CD：ボタンの外周に、残りの割合の弧（金、太さ 4u、12時から時計回りに減る）。地は暗く（α0.5）、中央に残り秒（10 秒未満は小数1桁）。使えるようになった瞬間に縁が一度光る（0.25 秒）。
- 押せない時（CD 中・被弾・ダウン・locked）は押しても何もしない。CD 中に押したらボタンが小さく揺れる。
- キー：U・I・O が枠1・2・3。
- 判定の広さは今と同じ（半径×1.15）。スキル枠と攻撃の判定が重なったら近い方。

## 2. スロット設定（戦闘前）
- 街にいる時だけ、回避の左下に小さな歯車のボタン（半径 30u）。押すとスロット画面（`dungeon_hud.gd` の難易度の画面と同じ作り）。
- 画面：上に3枠、下に持っている技の一覧。一覧の技を押す→枠を押すで入れる（同じ技が他の枠にあれば入れ替え）。×・外を押す・K で閉じる。
- 今は技3つを最初から持っていて、最初は枠1〜3にセット済み。取得の仕組み（落とし物など）は後で。
- セーブ：`progress.gd` に `skills_owned`・`skill_slots`（3つの id）を足す。前のセーブ（無い）なら既定値。
- ダンジョンの中ではスロットを変えられない（歯車を出さない）。

## 3. 技の作り（`player.gd`）
- 技の表を1か所に（id・使う clip・CD・当たりの列・エフェクト・倍率）。後で増やすのは表に行を足すだけにする。
- 使えるのは move・atk の状態から。連撃の途中は「当たりの CANCEL_AFTER 後」から割り込める（連撃は A に戻る）。回避・被弾・ダウン中は不可。
- 使っている間、移動の入力は向きだけ受ける（その場の技なので前進しない。絵の root の前進は 0.3 倍に抑える）。
- 威力は `progress` の攻撃の倍率を掛ける。敵の体力の帯・ダメージ数字は今の仕組み。
- 技の間は、被弾してものけぞらない（ダメージは受ける）。無敵にはしない。

## 4. 技3つ（新しいモーション無し。幅はエフェクト・当たり方で出す）
いずれも「その場」。突進はしない（ユーザー決定）。

### 枠1 乱れ斬り（id `flurry`）— 前方へ集中する多段。ボス・単体用の主力
- 絵：予備の `spare_combo`。今は `make_rana2.py` の GAME_CLIPS に無い → 足す（髪の色ずれは atkC と同じく色相で補正、光は "gold"）。コマの間引きは atkA と同じ 3 コマおき・24fps を基準に、全体 1.4〜1.8 秒に収まるよう調整。
- 当たり：前方 2.3m・奥行き ±1.1m に、10 回（動きの振りに合わせる。合わない所は等間隔）＋最後に強い1回。1回の威力は連撃 A の 0.45 倍、最後は 2.0 倍（合計で連撃1周の約 2.5 倍）。
- 当たった敵は、ラナの前 1.2〜1.8m へ毎回少しずつ寄せる（範囲から抜けないように。ボスは寄せない）。のけぞりは小さく（kb 0.3）、最後だけ吹き飛ばし。
- エフェクト：金の斬撃の弧を毎回、角度をずらして重ねる（`SL_*` の弧を、半径 0.85〜1.15 倍・角度 ±35° ランダム）。当たりの光は小さめ、10 回目以降で画面がわずかに揺れ続け、最後は大きい弧（SL_BIG）＋青い床の輪＋ヒットストップ長め。
- CD 8 秒。

### 枠2 地走り（id `rift`）— 前方へ伸びる遠距離の多段
- 絵：`atkB`（斬り下ろし）を流用。
- 当たり：斬り下ろしの当たりのコマから、前方へ地割れの衝撃が 3 回連続で走る（0.12 秒おき、1 回目 0〜3m・2 回目 2〜5.5m・3 回目 4.5〜8m、奥行き ±0.9m）。各回 連撃 A の 1.1 倍、敵を少し浮かせる（`lift_up` 2.5）。
- エフェクト：床を走る金と青のひび（`fx.bolt` を床に寝かせた形でよい）＋割れ目から立つ光の破片＋砂煙（`fx.dust`）。3 回目の先端で小さな衝撃波（画面のゆがみ）。
- CD 7 秒。

### 枠3 金の渦（id `vortex`）— 周囲を吸い寄せる多段。群れ用
- 絵：`hold`（回転斬り）を流用。長押しの回転斬りはそのまま残す（別の技として、当たり方とエフェクトで分ける）。
- 当たり：半径 3.2m の円（`shape` circle）。開始から 0.15 秒おきに 8 回、毎回 敵をラナへ 0.6m 引き寄せる（ボスは引かない）。各回 連撃 A の 0.5 倍。最後に強い1回（1.8 倍）で外へ大きく弾く。
- エフェクト：床に金の渦の輪（回転しながら縮む）＋周りを回る金の粒（内へ吸われる）＋最後に輪が外へ弾けて衝撃波。長押しの回転斬り（青い SL_SPIN）とは色・形で見分けられること。
- CD 12 秒。
