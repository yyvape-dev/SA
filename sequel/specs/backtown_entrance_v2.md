## 1. この区画の空気（ユーザーの指定＝事実）

- **売春婦のような怪しい人がいる空気。**

## 2. 前回の失敗と、その対策（今回の決まり）
| 失敗（事実） | 対策 |
|---|---|
| 歓楽街の要素が抜けて、市場とスラムだけになった | 3章の必須要素の表を、下絵・発注の前に照らし、報告に「入っている／入っていない」を書く |
| 世界観の文が抽象的で、建物ごとの説明（下絵の名前）が勝った | 建物ごとの説明は、世界観と3章の要素から書く。下絵の仮の名前をそのまま使わない |
| モックを添付しなかった | 発注にはモックを「世界・密度の見本」として添付する（明るさの扱いは未決 U1） |
| 暗さの決まりがモックの賑わいと矛盾した | 明るさの方針は未決 U1。決まるまで発注しない |
| 看板・ビジョンを壁に焼き込んだ | 光る物は別の部品（看板・ネオン・ビジョン・灯り）。壁は消灯で描く |
| 箱の側面に絵を引き伸ばした | 側面は横の壁の素材（4種）を実寸で繰り返す |
| 路地の奥に「パース無し」の文を入れて描けなかった | 部品の種類ごとに、文の組み合わせを確かめる（正面の立面図の文は壁だけ） |
| 合成で全体を見ずに発注した | **発注の前に、下絵＋届いている絵の合成をモックと並べ、ユーザーが判定する。通らなければ発注しない** |

## 4. 区画の形（決まっている所）
- 幅は約2画面（x −16〜16m）。カメラ D2、見どころは地面から0〜4m。
- 層（手前から）：手前の物（柱・箱）／歩く帯（何も置かない）／人混みと屋台の帯（店先）／**足場の枠（新規）**／建物の正面（下の帯 0〜5m）／路地の奥の書き割り。

## 6. 発注の決まり（U1〜U4 が決まってから）
- 添付：①その部品の下絵 ②画風の見本（届いた絵）③モック（世界・密度の見本。扱いは U1）。
- 文の組み合わせ：画風・世界（3章の要素を具体的に）・部品の種類ごとの文（壁＝正面の立面図、路地の奥＝奥行きあり、部品のシート＝切り離し）・光る物は消灯（壁）・文字は記号だけ。人は描かない（例外は U5）。
- 「paper lanterns」は書かない。
- 順番：まず主役の1枚（飲み屋）だけ頼み、チャットで判定してから残り。
- 発注の前に、2章の合成の判定を通す。

## 7. 人（絵には描かず、コードで動かす）
- 種類（候補）：客引き・娼婦風の女、怪しい男、酔っ払い、義手・義眼の用心棒、フードの売人、店の人（屋台の後ろ・酒場のカウンター）、通行人。
- 動き：短いループ（立つ・もたれる・手招き・煙を吐く・飲む・歩く）。作り方は、立ち絵 → 動画AIの短いループ → 透過の連番（Skill `video-to-sprite-pipeline`）。
- 置き場所：戸口・路地の口・階段・屋台の前・カウンター。歩く帯には置かない。暗く・彩度を落とす。
- 見た目の程度（露出など）・種類と人数は未決 U5・U6。
