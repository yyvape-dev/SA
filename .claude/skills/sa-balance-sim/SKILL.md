# 36週のバランスを自動で回して確かめる

## 1. 回す（300回×12通りで約20秒）
```bash
cd terrain && node tools/balance_sim.mjs 300 ../claude/balance_report.md
```
- 建て方 4 通り（`STRAT`：econ＝畑と酒場／def＝城壁と兵／bal＝混ぜる／fit＝bal と同じ順で場所は適地を優先）× 戦い方 3 通り（任せる／自分で戦う 勝率8割・6割を仮定。将軍戦は −15%）。
- 乱数は回ごとに固定（1000+i）。数字を変える前後で同じ条件で比べられる。
- 一騎打ちは出せる仲間のうち勝率が一番高い者（軍旗の間があれば2人）。ランカは常に出す。

## 2. 見る
- 勝率と負けた理由・章（どこで詰むか）。
- 章の終わりの 物資/民心/防衛力/兵：物資が余りすぎていないか、民心が100に張り付いていないか。
- 襲撃ごとの「防衛力−敵の規模」：+4 以上は任せても被害なし。0〜+4 が程よい緊張、大きすぎると作業になる。

## 3. 注意（事実）
- AI は単純（一覧の順に建てる・足りなければ兵と城壁・余れば発展と会話）。人のほうが上手い。差の傾向を見る道具で、絶対値ではない。
- 「自分で戦う」は、戦闘の勝ち負けを仮定の確率で決める。実際の手応えはユーザーの通しプレイで確かめる。
- 数字を変えたら、前の表（claude/balance_report.md）と並べて差を報告する。数字の変更はユーザーの承認を得てから。
