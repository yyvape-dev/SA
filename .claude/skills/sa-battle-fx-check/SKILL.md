# アクション戦闘のエフェクトをヘッドレスで撮って比べる

## 1. 撮る（1回 2〜3分。リポジトリ直下で）
```bash
node battle/tools/fx_shot.js /tmp/fx/gl                 # PixiJS 版（今の既定）
node battle/tools/fx_shot.js /tmp/fx/cv px=0            # 従来の Canvas 2D 版（比べる元）
python3 battle/tools/fx_cmp.py /tmp/fx/cv /tmp/fx/gl /tmp/fx   # → /tmp/fx/cmp_<場面>.png（左＝従来、右＝新しい、上から時刻順）
```
- 場面：slam（地を割る一撃）・wake（リリィの疾風の跡）・swirl（渦をまとう溜め）・arc（太刀2本）・ult（必殺の弧）・lance（突き）・hit（当たり・撃破・輪・吸引）・boss（敵将の撃破・癒し・星・追星・地走り・溜めの輪）・under（拘束の床と帯・強敵の気配・溜め）・star（星震）・foe1／foe2（敵の攻撃：予兆・突き・振り・斧の床割れ・被弾。敵ごとに当たりの瞬間を0にそろえた時刻）。しぼるときは3つめの引数に `arc,hit`。
- 2つめの引数は URL に足す引数：`px=0`（全部 Canvas）・`fxgl=0`（弧だけ前の形）。
- `FX_PLAY=1` を付けると、最後に70回ボタンを押して遊び、頂点の最大とエラーを出す。`DPR=2` で2倍の解像度（拡大して質を見るとき）。
- 仕組み：update を空にして時間を止め、`G.fx` に場面を積んで `t` をそろえ、`draw()` を呼んで撮る。敵の並びは乱数なので、左右で敵の数や位置が少し違うのは問題ない。
- 新しいエフェクトを足したら、`fx_shot.js` の `SCENES` に1行足す。
- Bash の timeout は 600000。2本は続けて実行する（並行させると重い）。

## 2. 見る（Read で cmp_*.png）
- 形・色・重ね順が従来と同じか（弧と突きはシェーダーの見た目に変わるのが正しい）。
- 丸い光（放射のグラデーション）が白く大きく出ていないか。線の端・点線・楕円の欠け。
- 足元の層（拘束の床・溜め）がキャラの後ろ、エフェクトがキャラの前にあるか。
- 標準出力：`{"px":true,"fx":true}`（Pixi とエフェクトの層が動いている）、`no errors`、頂点の数（重い場面で 1〜3万／コマが目安）。

## 表現の約束（2026-11-01 に現場の発信を調べて決めた。新しい技を作る・直すときに照らす）
- 予兆（溜め）→ 頂点（当たり）→ 余韻。余韻は急に消さない（地割れ・砂埃・岩片が残って引く）。
- 衝撃の輪は「中心から広がる」「均一にしない」：`vRingN`（太さと濃さのむら・途切れ）。一様な楕円1本は、格下の技か小さな当たりだけ。
- 地面に効いた手ごたえ＝砂埃（`vDustPuff`：影の土台＋明るい頂、大きさと寿命をばらす）・岩片（`vMakeDebris`）・地割れ（床の層 `FX_UNDER`）・揺れ。
- 広がるものは薄く、集まるもの（溜め）は濃く。溜めは渦を巻いて集まる（`fxSwirl`：砂埃の竜巻＋回る風の輪＋光の筋）。
- 格の差は「量と大きさと残り方」で：格上（ランカ・リリィ）は地割れ・岩片・砂埃・むらの輪を重ねる。格下は輪と光と火花まで。
- 色の役割をそろえる（味方の技＝青白・金、ラナ＝紅・金、敵＝赤、回復＝緑）。砂埃は光らせない（通常の合成）。
- 地割れ・えぐれ跡は線で描かない（太い線のコード感が出る）。現場の作り方＝割れ目の絵を地面に貼る（デカール）→ 中心からの距離で順に現す → 割れが走る先端と芯を光らせて冷ます → 浅い所から細らせて閉じる。素材は `battle/tools/crack_tex.py`（R＝深さ・G＝現れる順・B＝縁の欠け）、描画は pxfx.js の `ctx.decalGL`。Canvas 版だけ線の代わり（vDrawCracks）。
- 地割れの絵は画像AI（GPT）の手描きが一番合う（プログラムの割れは根・稲妻に見える）。頼み方：見本 `claude/order/ground_ref.jpg` を添付し「同じ画風・真上から・背景は透明」。取り込み `python3 battle/tools/decal_import.py <入力> <名前> radial|line`（縁のゴミの掃除・色の絵 _col.webp・データ _dat.png）。描画は `decalGL` に `col` を付ける。素材を替えたら pxfx.js の TEXV を上げる。
- 発光の十字は太さを固定しない：`vFlare`＝色をにじませた光（外は glow 色）＋筋は一気に細りながら伸びる。
- 突進の技は「線」でなく、体ごと包む太い帯（slashGL の直線、素材 smash）＋まとうオーラ＋先頭の衝撃の弧＋えぐれ跡。
- 重さ：むらの輪のような短い線の連なりは丸い端にしない（頂点が数倍）。頂点の最大は 3.5万／コマ程度まで（PX.vstats）。

## 敵将・将軍・ジャストガードの確認（遊びの仕組みを変えたとき）
- `node battle/tools/boss_test.js [gen=g1〜g6]`（2〜4分）：敵将の大技（大振り・連撃・突進）が立ったままだと当たる／大振りと連撃の最後をジャストガードで無傷＋崩し／突進はジャストガード不可・回避で抜ける／大技中はひるまない／突進を抜けられる回避の押す時刻の幅（charge_window）。撮影は /tmp/bst。将軍を足したり大技の数値を変えたら、その将軍で回す。
- `node battle/tools/gen_shot.js [g1,g2,…]`：将軍の大きさ・歩き・攻撃の軌跡を撮る（/tmp/gen）。
- `node battle/tools/jg_test.js`：ジャストガードの受付（早すぎ・遅すぎ）とスロー。
- 実機の確認 URL：`index.html?battle=1&waves=3&boss=1&al=mina&gen=g1`（g1〜g6＝章の将軍。付けないと雑兵の大きい版）。
