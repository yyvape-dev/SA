## 1. 工程（どの技も、この順で。抜けたら手戻りになる）
1. **お手本を決めて測る**：録画をコマに分け、予兆・当たり・余韻の時間、層の数、画面を覆う割合、色の組を数字にする（シークせずに録る。0.25倍速なら細かく測れる）。
2. **設計表**（`sa2-skill-craft` の表）＋**重要度の段**（4.）を決める。
3. **素材を集める**：手持ち→無料（Kenney 等）→外部AIの発注→有料、の順。無料を試す前に有料の判断を求めない。
4. **素材を整える**（5.）：黒地・白黒・明るさを RGB に（★L8 は WebGL2 で表示されない）・中に濃淡（侵食用）。
5. **動かし方を決める**（6.）：侵食・グラデーションマップ・大きさの曲線・マスク走査。置いて薄くするだけ（スタンプ）にしない。
6. **組み立てる**（7.）：層・合成・奥行き（2.5D の前後）。
7. **手応え**（3.）：止め・揺れ・白光り・音。
8. **大技なら演出**（8.）：暗転・カットイン・全画面・白飛び・散り。**大技の締め（全画面の炸裂）は 12. の型で Godot で描いて焼く**。素材を1枚出して拡大・回転・薄くするだけは不可。
9. **確かめる**（10.）：お手本と同じ瞬間で並べる、白黒・明暗の背景、**iPhone 実機**。

## 2. エフェクトの原則（vfx-realtime）
- 形・時間・色の3軸。形＝一目で読める輪郭・量感・向き。時間＝予備動作→動作→余韻。色＝明暗の差→彩度の順。
- 予備動作が衝撃の8割。二次の動き（火花→小さな火花、爆発→煙→残り火）。引き算も力。
- 層で組む：芯（加算）＋にじみ＋煙・土（通常の合成）＋破片。1つのエミッターで全部やらない。
- 合成：光を出すもの＝加算。遮るもの（煙・土・破片）＝通常の合成（★加算だけの層では暗くできず、灰色の光の塊になる）。白い背景と黒い背景の両方で確かめる。
- 寿命は±20% 以上ばらつかせる。色は寿命の中で変える。炎・煙にはノイズ。動く物から出る粒は速度を受け継ぐ。止め・スロー中は粒も止める。
- 連番：主役は1コマ 128px 以上。コマ間が段々ならコマ補間（`naraku-vfx` 8）。

## 3. 手応え（game-feel）
- 1回の当たり＝約100ms 以内に 5〜8 個の反応：音・粒・止め・白光り・ノックバック・揺れ・数字。誇張は一瞬で元に戻す。
- **止め（ヒットストップ）★**：SA2 は `battle.freeze`（ラナと敵だけ止まり、エフェクトは動く）。**Engine.time_scale は使わない**（全体が遅くなり、戻すタイマー・揺れまで巻き込む事実あり）。今の値：通常 0.05秒・強い当たり 0.09秒。
- 揺れ：trauma（0〜1。小 0.10〜0.20／中 0.30〜0.50／大 0.70〜1.00）を当たりで足し、毎秒 1.0〜1.5 減らす。揺れ量＝trauma²。カメラの offset（8〜16px, 6〜10px）と回転（0.05〜0.12rad）を、sin を重ねた滑らかな値で動かす（毎フレーム乱数はジジジと鳴るので使わない）。体ではなくカメラを揺らす。SA2 は `battle.shake`（技ごとの値は vfx_overhaul.md）。
- 止めは1回の当たりに1回だけ。押しっぱなしの技で毎フレーム掛けない。入力は止めない（先行入力を通す）。
- 白光り：塗り替えでなく加算 40〜60% を 1〜2 コマ（真っ白の塗り替えは絵が消えてシルエットになる）。
- 動きはイージング（ポン＝BACK+EASE_OUT、止まる＝CUBIC+EASE_OUT、溜め＝EASE_IN）。つぶし伸ばし (1.3,0.7)→戻す。
- ダメージの数字：横にランダムにずらし、重なっても読めるように。
- 光の点滅は1秒に3回まで。

## 4. 重要度の段（全エフェクトで共通。値は1か所の表で持ち、技ごとにばらばらに決めない）
| 段 | 揺れ | 止め | 粒 | 追加 | SA2 の例 |
|---|---|---|---|---|---|
| 小 | 弱 | なし | 0〜4 | 小さな音 | 取得・足音 |
| 中 | 中 | 0.05秒 | 6〜12 | 白光り・火花 | 通常の当たり |
| 大 | 強 | 0.09〜0.15秒 | 20〜40 | 白光り＋寄り＋色収差 | 技の最後・撃破・大技 |

## 5. 素材の作り方・頼み方（外部AI・既製品の加工）
- 黒地・白黒・縁が柔らかい。色はゲームで付ける（グラデーションマップ）。
- **中に濃淡を持たせる**：芯ほど明るい（侵食で外・細い所から消えるため）。のっぺりした白一色は侵食が効かない。
- 向きのある形は向きを決めて頼む（例：右端＝刃の頭で太い、左端＝尾で細い）。
- 消える順番を別に持てるなら持つ（`sa-vfx-texture`：G＝消える順番、芯ほど大きい）。
- 同じ画風の単体素材は、列×行の1枚のシートで頼むと画風と色がそろう（`naraku-vfx`）。
- ★漫画風（平塗り）の既製品は、夜の街の塗りと合わない（REEBO の爆発で事実）。

## 6. 素材の動かし方（置いて薄くするだけにしない）
- **アルファ侵食**：寿命でしきい値を上げ、smoothstep(しきい値±幅/2, 値) で縁を柔らかく食う。ゆっくり流れるノイズを掛けると毎回崩れ方が変わる。逆に回せば「現れる」。
- **グラデーションマップ**：白黒の明るさ→色の帯（白→金→紅→透明）。1色で染めない。寿命で帯を暗い側へずらす（冷める）。帯のテクスチャは小さく（大きいと段が出る）。
- **大きさの曲線**：2〜3コマで 0→1.1〜1.2（ease-out）、その後ゆっくり。速い物は進む向きに伸ばす。
- **斬撃**：三日月を丸ごと出さない。弧に沿ったマスクで先端が走り、尾から侵食で消える。中の模様は UV を流す。
- **輪**：強い当たりだけ。広がるほど細く、侵食で消す。毎回同じ輪は照準の印に見える。
- Godot：粒子の canvas_item シェーダーでは vertex() の INSTANCE_CUSTOM.y が寿命の進み（0→1）。

## 7. 組み立て（層・奥行き・SA2 の描画の事実★）
- ★SA2 は 3D が画面全体を覆う。2D の層（`fx2d.gd` の SubViewport）は**常に 3D の手前**＝敵の体の手前に出る。床に寝る物・敵の奥に出る物は、3D の板（`sprite_bb` 型のビルボード）で奥行きを持たせる。2D の層は画面全体の演出と、手前で良い物だけ。
- ★2D の層：SubViewport だけ hdr_2d＋背景 Canvas の glow（閾値 0.7）、光らせる色は RAW 1.3〜2.0（芯は 2.0）。**画面全体の hdr_2d は使わない**（衝撃波のゆがみと組み合わさると白い横の帯が出た）。
- ★3D の glow（ネオン・灯り）：閾値 0.78・SCREEN。Compatibility でも glow は使える（公式の表）。
- ★iPhone の Safari では、パソコンのブラウザで動く自前のシェーダーが動かないことがある（REEBO で白い四角が出た）。新しいシェーダーは iPhone で確かめるまで「未確認」。確実にしたい物は**連番に焼く**（`tools/bake_reeboo.gd` の型）。粒は CPUParticles2D の方が確実。
- 粒を速さの向きにそろえる設定は、減速で止まった粒が画面の端まで白い線になる（★事実）→ そろえない。

## 8. 大技の演出（DNF 真覚醒を測った事実）
- 流れ：背景の暗転 → カットイン（顔・目のアップの一枚絵。滑らせる・寄る）→ 画面のほぼ全部を覆う光 → 一度真っ白 → 粒が散って戻る。
- 粒の散り：形（花びら・玉・筋・炎の舌・黒い破片）、色（白い芯＋金・橙・桃・青）、大小を混ぜる。縁の硬い塗り＋にじみ。黒い破片を光の上に重ねて締める。
- カットインの一枚絵は外部AIが得意（構図のある一枚絵）。動きはコード。

## 9. 音（未整備。SA2 に効果音があるか、まずユーザーに確かめる）
- 当たりの音は3層：鋭い立ち上がり（ここが「切れ」）＋胴（重さ・材質）＋低音。ゲームの当たりは短く（数百ms）、ファイルの頭に立ち上がりを置く（無音があると遅れて聞こえる）。同じ音は3〜5種を用意し、高さを少しランダムに。
- 音と絵の当たりのコマを同じ瞬間にそろえる。

## 10. 確かめる（判定のときに見る点）
- お手本と同じ瞬間（当たり前60ms〜後600ms）で並べた画像。言葉だけで判定を求めない。
- 当たりの瞬間に反応が何個重なっているか（5〜8）。
- スタンプになっていないか（侵食・色の帯・大きさの曲線・UV の流れがあるか）。
- 白黒で読めるか。夜の暗い画面で沈まないか、白い塊に飛ばないか（群れに当てたとき）。
- 光るものが加算、遮るものが通常の合成か。
- 2D の層の物が、奥にあるべき所で手前に出ていないか。
- **iPhone 実機**：見え方（パソコンと違うことがある）と重さ（重なり平均2倍・最大4倍、粒は PC の半分以下、画面のゆがみは大技の一瞬だけ）。

## 12. 決まった方式（2026-11-12 ランカで確立。ユーザー評価「すげえ良い」。全てのゲームの基本）

### 12-1. 素材：白黒の素材＋コードで色・侵食・動き（SA1 と同じ方式）
- 外部AI（GPT 画像）に、前に作った白黒の素材を添付して「同じ質感（黒地・白黒・柔らかい縁・中に濃淡・芯ほど明るい）で別の形」と頼む。1件1枚、発注票（Skill `art-order-sheet`）で渡す。
- 基本の6種（キャラが変わっても形は使い回せる）：①床に寝る衝撃の輪（太さのむら・途切れ）②星形の閃光（6〜8本、長さ不ぞろい）③光の柱（縦長、縁が揺らぐ）④気の帯（右端＝頭が太い、左＝尾）⑤花びら・破片 8 枚のシート（4×2）⑥光の爆ぜ（放射の筋＋粒＋ちぎれた欠片）。斬撃の帯3種とノイズは SA1 の物（`terrain/tools/fx_src/`）を使い回す。
- 届いたら：黒を透明に、RGB＝明るさ、A＝形、余白を切って長辺を縮める（`make_vfx_tex.py` の型）。シートはマスごとに切って正方形に並べる。
- ゲーム側：色の帯（白→淡い色→濃い色→透明）・寿命で侵食（芯ほど遅く残る）・大きさの曲線。小技は 3D の板（★SA2 は `fx.tex_quad`、`aspect`・`grow_x`・`ang`・`band`）で、当たり＝閃光（強い当たりは爆ぜも）、突き・弾＝帯、床＝輪、のように役割で選ぶ。
- 花びらなど色の付いた小物は、白黒の素材に色を掛け算すると中ほどの灰色で濁る（朱が茶になった事実）→ **明るさ→色の対応で塗る**（暗い所＝本来の色、明るい根元＝白に寄せる）。光の層に埋もれないよう、光の上に重ねる。

### 12-2. 大技の締め：Godot で描いて焼く（`naraku-vfx` 7. の型を SA2 に移したもの）
- 焼きのスクリプト（xvfb の実描画・`--fixed-fps 30`・乱数固定＝毎回同じ）で、**3回に分けて描いてコマを保存**：光の回（黒地・加算・HDR＋Glow）／抜きの回（透明地・通常の合成：黒い破片・地を這う土煙）／上の回（透明地：花びら）。
- **時間の型**（1.0〜1.3 秒）：
  1. 予兆 0.25 秒：外から中心へ集まる光の筋（EASE_IN）、中心の光が育つ、床の輪が閉じる。何も起きない空白を作らない。
  2. 炸裂：芯の閃光を 2 コマだけ大きく → 爆ぜの絵を**中心から外へ現す**（0.1 秒で 0.35→1.0、その後ゆっくり 1.15）。**回さない**。外と暗い所から侵食で消える。色は寿命で冷める。
  3. 散り：光の筋（速さで伸び、減速）、粒（減速＋重力、2色）、床の輪（広がるほど細く）。寿命はばらつかせる。
  4. 締め：黒い破片（放物線・回転）と地を這う暗い土煙を通常の合成で重ね、光だけにしない。花びらは飛び出してからひらひら落ちる。
- まとめ（`pack_ranka_finale.py` の型）：光は「RGB の最大値＝不透明度、色は割り戻し」、抜きは premultiplied を割り戻し、光を抜きの上、上の回をいちばん上に → straight alpha の1枚のアトラス。1コマ 512×288 程度。
- ゲーム側は**絵をめくるだけ**（★SA2 は `ranka_fx.seq`、Sprite3D・自前のシェーダーなし＝iPhone で確実）。炸裂のコマを当たりの時刻に合わせて少し前から出す。
- 大きさ・白さの調整：画面の白い画素の数を数えて報告する。白が画面の大半を覆うなら、炸裂の絵を小さく・倍率を下げ・芯は短く。3D の glow が掛かる画面では焼いた絵を少し暗く出す（★SA2 は 0.8）。色収差は強いと虹色で安っぽい（0.35 程度）。

### 12-3. 見直し方（作ったら必ず）
- 当たり・炸裂の前後を **0〜600ms で 10 コマ**撮り、前と今を上下に並べる。見る点：予兆があるか／1コマで全部出ていないか／回しているだけでないか／消え方が全体に均等に薄くなるだけでないか／白が画面を覆ってキャラが消えていないか／地面と暗い物があるか。
- 言葉だけで判定を頼まない。並べた画像を送る。

### 12-4. Web の取りこぼし（★事実）
- 新しい素材のフォルダが、Web の書き出しで本体からも地区のデータからも外れ、iPhone で**白い四角**になった（パソコンのテストでは全部そろっているので気づけない）。→ 書き出しで「どの pck にも入っていない絵」を検出して止める（`export_web.py`）。新しい素材のフォルダを足したら、どの pck に入るかを決めてから書き出す。

## 11. Godot 4.7 の実務（godot-particles ほか）
- Web は Compatibility（WebGL2）。WebGPU は無い。
- 一回きりの粒：emitting=false → 置く → restart()。finished 直後に emitting=true にしない。使い回す。
- 色の変化の最後は不透明度0。一点から出さず、形（円・箱）から出す。乱流は Web で重い。軌跡は local_coords=false。amount_ratio では軽くならない。
- シェーダー：2D は canvas_item、色の uniform は source_color、画面を読むのは hint_screen_texture（Web で重い・iPhone で要確認）。
