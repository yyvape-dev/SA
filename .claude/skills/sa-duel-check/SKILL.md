# 一騎打ちをヘッドレスで撮って確かめる

## 1. 撮る（1回 2〜4分）
```bash
node terrain/tools/duel_shot.js <章1〜6> <仲間,仲間> <win|lose|rand> <出力フォルダ>
```
- 例：`node terrain/tools/duel_shot.js 5 lily,ranka win /tmp/d5`（第5章、リリィとランカ、勝ちに固定）
- 仲間を空 `""` にすると初期選択のまま（第6章はラナとランカ）。キー：rana（第6章だけ）・mina・garou・sera・ranka・lily。
- 試しは軍旗の間がなくても2人で挑める（`G.testPair`）。
- 出力：`sheet.png`（選出画面＋1.5秒ごと14枚＋結果）、`stage.png`（舞台だけを拡大した14枚）。標準出力に選択の文言とページのエラー。
- 攻撃の瞬間（間合い・寄り・エフェクト）を見るとき：`DS_INT=120 DS_N=30 node terrain/tools/duel_shot.js ...`（0.12秒おき30枚。最初の攻撃は s17〜s26 あたり）。ページの console で `[duel]` から始まる行は標準出力に出る。
- Bash の timeout は 600000 にする。2本以上撮るときは、続けて実行する（並行させると重い）。

## 2. 見る（Read で stage.png → 必要なら sheet.png）
- 見切れ：剣や体が舞台の左右で切れていないか。
- 大きさ：仲間同士・敵将と並べて、頭の大きさがそろっているか。
- 色：背景から沈んでいないか（陰の層 `.sh` で暗くなりやすい）。
- 黒い四角や枠：クラス名が既存の CSS と衝突していないか（前例：`.fr`）。
- 合わせ技：勝ちに固定すると、最後の合で `LINK` のカットインが出る。
- 気になるコマは、`s01〜s14.png` を切り出して拡大する。

## 3. 終わったら
- 結果をユーザーに一言で（何を見て、何が直ったか）。実機は未確認と明記。
- 絵の meta（duel_meta・side_meta）を変えたら、`?v=` を上げる（main.js と battle/ally.js の両方）。
