根拠：sa2_story_bible_20261106.md、sa2_gameplay_story_structure_principles_20261108.md、第一・第二章の各制作稿。SA1正史の優先と裁きの分岐維持。
**重要：五幕構成は正本に記された「提案」であり確定章数ではない。以下は検証用の暫定構造。**

## 全体原則
- 物語の各節に「目的／プレイヤー操作／戦闘の理由／結果／次への動機」を必ず定義する。往復・会話・荷運びを長尺の主操作にしない。
- 戦闘は開始早期に体験させる。ただし帝国の一般市民・工事関係者を安易に敵化しない。帝国の希望と矛盾を併存させる。
- ボス戦は人物・危機・選択の帰結として設計し、単なる章末の定型戦にしない。
- 戦闘可能なキャラクターと技能はSA1設定・実装を検証してから確定。ランカの早期加入を前提にしない。
- 戦闘に必要な素材・実装が未確認のため、所要時間は**測定値ではなく暫定目標**。初回戦闘まで操作開始から10〜20分以内を仮目標、以後は非戦闘の必須操作が15分以上連続する箇所をレビュー対象とする。物語の緊張と実測に応じて調整。

## 操作密度の仮設計（第1・第2章を先行）
| 単位 | 仮目標 | 合否の確認方法 |
|---|---|---|
| 初回能動操作 | 導入後できるだけ早期 | Godot実機で開始から操作可能まで計測 |
| 初回戦闘 | 10〜20分以内（仮） | 初見テストで開始から戦闘入力まで計測 |
| 非戦闘の長い連続 | 15分超をレビュー対象 | 台詞送りを含む通しプレイで計測 |
| 戦闘以外の操作 | 結果・判断・移動の意味を持つ | 操作を取り除いても内容が同じなら再設計 |
| 戦闘 | 避ける・守る・突破する等の目的を持つ | 敵を倒す以外の勝利条件も評価 |
| 説明台詞 | 操作で見せられることは操作で示す | 連続会話時間と冗長な説明を記録 |

## 第一章：既存12景を維持するための改訂配置
- 第1〜3景：ユーザー採用済みの導入。**本文・時系列は原則固定**。外港探索は短く、過度な移動を要求しない。
- 第4〜6景：既存の式典・技術披露の流れを確認し、**帝国側の公開演習／警備訓練等で戦闘操作を初導入**する候補。外交的な安全確保と整合しない場合は別の自然な接続を設計し直す。観客・兵士を無理由に攻撃させない。
- 第7〜9景：工芸院・修理小路・商談。既存の見学と運搬を圧縮し、戦闘で学んだ操作の短い応用または目的のある探索に置換。
- 第10〜12景：交通トラブル、夕食、夜の境目。既存の女性士官登場・仲間の会話・章末を維持。事故対応は短い危険回避操作に絞る。
- 戦闘導入の確定前に、既存第4〜6景とSA1戦闘の操作・キャラ能力を必ず確認する。

## 第二章：既存12景を維持するための改訂配置
- 第1〜2景：朝の予定と街への移動を圧縮。第1章からの課題を短く引き継ぐ。
- 第3〜5景：市場の屋台、工房、案内人。**単なる見学の連続を減らし**、立体通路・高低差・障害物の横スクロール操作を中心にする。
- 第6景：仲間の再合流。次の目的を具体化し、説明の繰り返しを削る。
- 第7〜8景：再訪と荷揚げ場。安全な移動・搬入問題の提示は残すが、後半の主目的を荷運びだけにしない。
- 第9景：既存の荷運びミニゲームを短縮し、**街区で発生する戦闘を含む危機対応ステージ**に変更する。戦闘の理由・敵の種類は世界観と既存設定の整合を確認して決定する。
- 第10〜11景：戦闘後の被害・責任・街の生活の継続を描く。工事監督と住民を敵対勢力と短絡しない。
- 第12景：章末の会話と次章への具体的な行動目標を再設定。ネタバレ防止のためユーザー報告に内容を出さない。

## 戦闘・操作の仕様を確定する前の依存条件
1. SA1戦闘コードとSA2の予定戦闘方式を確認（2.5D横スクロール、操作人数、攻撃／回避／ガード／交代、敵AI、HP・敗北）。
2. 現在のGodotプロジェクトのシーン構造・利用可能なキャラ絵と敵絵を確認。実際の実行環境がない場合は未検証とする。
3. 公開演習を採用する場合、帝国が他国の賓客に戦闘操作を認める理由と、安全管理を台本上で成立させる。
4. 市街戦を採用する場合、戦闘による住民・外交への影響と敵の出現理由を確定し、無根拠な雑魚敵を置かない。
5. ランカの加入時期・SA1分岐・主要人物の既存設定を壊さない。

## 制作ゲート
- Gate A：第一章の初戦が物語上自然か、操作して面白いか（台本と操作設計）。
- Gate B：第二章の市街戦が街の描写と矛盾しないか、護衛・救助がゲームとして成立するか。
- Gate C：Godot実画面と実操作で初戦到達時間、会話密度、戦闘テンポを測る。
- Gate D：A〜Cで問題があれば第三章以降の詳細稿を固定しない。
