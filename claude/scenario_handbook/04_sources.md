# 出典と調査ノート
調査日：2026-11-02／[目次](README.md)

## 調査の範囲と読み方
作家本人の公式資料、執筆者が話すWriting Excuses、ゲーム制作者の公式文書・講演資料を中心に確認した。検索結果だけで内容を断定せず、以下の本文・公開資料を開いている。書籍全巻や講演動画全編を視聴したという意味ではない。

資料の短い要約と、教科書独自の設計モデルを区別する。SAの診断と教材例は本教科書の編集判断であり、出典の著者の見解ではない。学術研究によって面白さの普遍法則が実証されたという主張はしない。長文の転載や翻訳は行わない。

<a id="s1"></a>
## S1. Aristotle『Poetics』、S. H. Butcher訳
- [公開本文：Project Gutenberg](https://www.gutenberg.org/files/1974/1974-h/1974-h.htm)
- 確認箇所：VIII–IX、XI、XVを中心とする出来事のつながり、認知と逆転、人物の言動の整合に関する議論。
- 要点：物語の出来事を、ただの時系列ではなく、ありそうな／必然的な結びつきとして捉える。
- 本書での利用：章の因果、人物の選択に基づく決着、証拠の設計。
- 限界：古代の悲劇論を、現代の全ゲームの評価基準にはしない。主人公が必ず悲劇的に転落すべきだという提案ではない。

<a id="s2"></a>
## S2. Brandon Sanderson公式、2025 Guide to Plot（Lecture #2）
- [公式講義ノート](https://www.brandonsanderson.com/blogs/blog/brandon-sandersons-2025-guide-to-plot-lecture-2)
- 公開：2025-01-24。確認：公式記事本文。リンクされた動画全編の視聴はしていない。
- 要点：物語が作る期待、進展、回収の関係で、展開を点検する。
- 本書での利用：冒頭の問い、中盤の進展、結末で応える内容の整理。
- 限界：一つの作家の実践的な枠組み。あらゆる作品が同じ構成である必要はない。

<a id="s3"></a>
## S3. Brandon Sanderson公式FAQ、How Do You Make Characters Feel Like Regular People?
- [本人による回答](https://faq.brandonsanderson.com/knowledge-base/how-do-you-make-characters-feel-like-regular-people/)
- 要点：人物を役割に閉じ込めず、本筋以外に大切にしていることを考える。人物の発展に応じて計画を見直す。
- 本書での利用：生活、好み、主人公以外の目的を持つキャラ設計。
- 限界：人物の自律性は、ユーザーの確定設定を無断で変える理由にはならない。

### 補助資料：同公式 Lecture #6
- [Customizing your Character](https://www.brandonsanderson.com/blogs/blog/customizing-your-character-brandon-sandersons-writing-lecture-6-2025)
- 公開：2025-03-04。確認：公式記事本文。
- 要点：動機、価値観、人格、独自の声という観点で人物を考える。変化の大きい人物だけが選択肢ではない。
- 本書での利用：人物シート、声の描き分け、変わらない人物を排除しない方針。

<a id="s4"></a>
## S4. Writing Excuses 10.25、What Makes a Scene?
- [公式ページ・掲載トランスクリプト](https://writingexcuses.com/writing-excuses-10-25-what-makes-a-scene/)
- 話者：Brandon Sanderson、Mary Robinette Kowal、Dan Wells、Howard Tayler。
- 要点：場面の定義は一様ではなく、目的・変化・開始と終わり・出来事の処理を通じてテンポを作る。
- 本書での利用：場面カード、静かな余韻、日常の機能。
- 限界：全場面を「目標→失敗」に固定するための資料ではない。本書のカードは独自に整理した実務用の道具。

<a id="s5"></a>
## S5. Writing Excuses 17.34、Developing Subtext
- [公式ページ・掲載トランスクリプト](https://writingexcuses.com/17-34-developing-subtext/)
- 話者：Dan Wells、Mary Robinette Kowal、Maurice Broaddus、Howard Tayler。
- 要点：言葉と、その周囲の文脈との間に、明言されない意味が生まれる。
- 本書での利用：台詞の目的、具体物・行動による本音、心理説明の調整。
- 限界：全てを曖昧にする技法ではない。ゲームで必要な指示・選択の意図は明確にする。

<a id="s6"></a>
## S6. Becky Slitt／Choice of Games、How to Write Intentional Choices
- [公式記事](https://www.choiceofgames.com/2016/12/how-to-write-intentional-choices/)
- 公開：2016-12-22。確認：記事本文。
- 要点：選択の意図を持てるよう、見込まれる結果、危険、判定があるならその性質について情報を渡す。
- 本書での利用：選択前の情報、選択文と実行結果の一致。
- 限界：成功結果を全部公開するという意味ではない。探索や不確実性を楽しむ設計もあり得る。

<a id="s7"></a>
## S7. Dan Fabulich／Choice of Games、By the Numbers
- [How to Write a Long Interactive Novel That Doesn't Suck](https://www.choiceofgames.com/2011/07/by-the-numbers-how-to-write-a-long-interactive-novel-that-doesnt-suck/)
- 公開：2011-07-27。確認：記事本文。
- 要点：分岐を合流させながら、以前の選択が後の判定・展開に効く設計を、数値による管理とともに紹介。
- 本書での利用：一本道と選択の両立、後の反応の台帳。
- 限界：「数値が変われば必ずプレイヤーに意味が伝わる」とは本書では扱わない。個別フラグと集約値は用途で比較する。

<a id="s8"></a>
## S8. inkle、Writing web-based interactive fiction with ink
- [公式チュートリアル](https://www.inklestudios.com/ink/web-tutorial/)
- 補助参照：[公式ガイドの公開案内](https://www.inklestudios.com/2022/01/20/ink-official-guide)
- 確認：チュートリアル本文。ink全機能の検証は行っていない。
- 要点：選択、分岐と合流、訪問済み状態などを使い、文章の流れを制御する方法を示す。
- 本書での利用：既読条件、分岐の合流、状態を伴う台本の考え方。
- 限界：SAをinkへ移植する提案ではない。SAの実装可否は現行コードで確認する。

<a id="s9"></a>
## S9. Harvey Smith & Matthias Worch、What Happened Here? Environmental Storytelling
- [講演者の公開案内](https://www.worch.com/lectures/)
- [GDC 2010公開スライド・ノートPDF](https://media.gdcvault.com/gdc10/slides/Smith_Harvey_WhatHappenedHereWeb_Notes.pdf)
- 確認：公開PDFの定義・環境の役割・プレイヤーの解釈に関する箇所。84ページの資料。講演動画全編の視聴ではない。
- 要点：空間や物の配置・状態を組み合わせ、プレイヤー自身が起きた出来事を読み取れるようにする。
- 本書での利用：生活の痕跡、運営や戦闘の結果を世界に残す方針。
- 限界：HUDや報告文への応用は本書の提案。全ての台詞を環境表現に置き換える主張ではない。

<a id="s10"></a>
## S10. Brandon Sanderson、Sanderson's Second Law
- [公式エッセイ](https://www.brandonsanderson.com/blogs/blog/sandersons-second-law)
- 確認：能力、制約、倫理・弱点に関する本文。
- 要点：能力の大きさだけでなく、制約やできないことが人物・世界の興味につながる。本人も絶対法則ではないと明記する。
- 本書での利用：強者がいても成立する課題、倫理的選択。
- 限界：政治・信頼への応用は本書の編集判断。ランカの新しい弱点を確定する根拠ではない。

## 調査からSAの提案へ至る関係
| 資料で得た観点 | SAに向けた編集判断 |
|---|---|
| 出来事の結びつき | 政策・救出・約束を後の週に残す |
| 期待・進展・回収 | 父の死、石を投げた民、ミナの依存を章ごとに進める |
| 役割以外の生活 | 食事、手入れ、釣り、仕事から人物を魅せる |
| 文脈から生まれる意味 | 心理の自己解説を減らし、具体物と相手への態度を使う |
| 意図できる選択・後から効く選択 | 慈悲／厳格だけでなく何を覚えるべきか検討する |
| 空間に残る痕跡 | 守った結果を住民・建物・報告へ戻す |
| 能力と制約 | 強者の設定を維持したまま、力では決められない課題を作る |

「告白→理解→行動→信頼回復を分ける」「人物・場面・証拠の各シート」「レビュー項目」「SAの優先順位」は、本教科書が組み立てた提案である。
