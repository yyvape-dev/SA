# ストーリー増量の設計（2026-11-01、ユーザーの選択から）

## 決まったこと（ユーザー）
* 秘密は無い。GitHub のストーリーが全て。Claude Code で書いてよい。
* 軸：ラナの成長（民の信頼／守られる→守る／決断の重さ／父の死・叔父への感情）。全部。
* 間の週：章の中盤の出来事・民の嘆願・仲間の個別の話（絆）・毎週の朝の一幕。全部。量は多め。
* 将軍戦は三段：①任せる（味方の前哨戦）→②一騎打ち（仲間 vs 敵の副将）→③ラナのアクション戦（章のボス。隣に章の因縁の仲間）。
* 敵の副将＝山賊頭グレンが毎章しつこく出る。
* 誇りある将（ボルグ・エルザ・ヘルマン）はすぐ合流しない。何度か戦って敗れ去り、対話と葛藤の中で「そうせざるを得なかった背景」が少しずつ分かる。章の中盤の強制のラナ戦（アクション）も足す。
* 選び方（嘆願・中盤）は、結末の民と仲間の声に反映（筋は一本道）。

## 仲間の成長（ユーザー、2026-11-01）
* ミナ：歪な依存と独占欲。救われた恩に嘘はないが、自分以外に寄る辺を無くした姫との暮らしに充足を覚えていた。成長していくラナに葛藤し、「そこまでする義理はない、一緒に逃げよう」と言ってしまって自分の本音に気づく。それでも民も友も国も自分も見捨てないラナの姿に、その横に並ぶべき者になろうと成長する。（第1章の夜「二人で暮らすのも悪くない」→ 絆の話 → 第5章で「一緒に逃げよう」→ 第6章で隣に並ぶ）
* ガロウ：傭兵として根を張って守ることから逃げていた弱さ。無責任に力を振るう日暮らしが、臆病で弱い生き方だったと気づいていた。仲間の姿で改めて実感する。奪われる恐ろしさからも、奪う恐ろしさからも、もう逃げない。弱さを抱えて強くなる。（ボルグとの再戦の中で）
* セラ：記録→自分の声。「数字は嘘をつかない」と記録の陰にいた彼女が、姉エルザとの衝突を経て、民や姉に自分の言葉で語る。姉妹の和解、宰相見習いへ。
* ランカ：救国の女王になっていくラナの姿を見て、昔のシリアン（国を追われた王子。国を取り戻して王になったが、ランカは即位を見届けて去った）と、彼についてきた「反乱軍」と呼ばれた仲間たちと歩んだ日々を思い出す（仲間は国を取り戻し人魔戦争に至る中で殆どが死んだ。ランカが弔ってきたのは彼ら）。自分が何のために戦い、何を弔ってきたのか。第6章の中盤、「国を追われた自分はただの被害者ではない。治世も民も分からなかった。そんな自分がもう一度王座に座るのも過ちでは」と悩むラナに、「英雄である必要はない、ただ自分の大事にする世界を侵されないように生きる、それでいい」と諭し、今の自分（釣り人）を自嘲気味に振り返る。
* リリィ：昔は（大戦で一人に全部を背負わせ、心をすり減らして消えさせた）ランカを守りきれなかった。今ならできる、と覚悟を改める。

## 1章の週の型（6週）
| 週 | 中身 |
|---|---|
| 1 | 章の始まり（なぜこの地へ進むのか＝民の嘆願・村の解放）。冒頭でセラ（加入前はミナ）が「◯◯に進んだ／◯◯が加わった」と報告 |
| 2 | 襲撃（前後に短い会話） |
| 3 | 中盤の出来事①（筋が進む会話。選択肢あり）＋民の嘆願 |
| 4 | 襲撃（前後に短い会話） |
| 5 | 中盤の出来事②＝誇りある将との再戦（強制のラナ戦）か、葛藤の会話 |
| 6 | 将軍戦の三段（①前哨戦 ②グレンと一騎打ち ③ボス戦）→ 章の終わり |
* 毎週の朝：報告に、その週ならではの一言二言の掛け合い（仲間が順に）。
* 仲間と過ごす：絆1・2・3で短い個別の話（5人×3）。

## 章ごとの筋（案）
### 第1章 逃亡の朝（グレン）
* 民はラナを恐れる。子どもが逃げる。③でラナが初めて自分の剣で民を守る（ミナが並ぶ）。
* 嘆願：麦を盗んだ少年（赦す／罰する）。グレンはまだボス。副将は子分。

### 第2章 斧の値段（ボルグ。副将グレン）
* グレン、ボルグの傭兵団に雇われて再登場（仕返しに燃える小悪党）。
* 中盤①：東の村と麦を分け合う取り決め。ラナが初めて人前で約束を口にする（守る側への一歩）。
* 中盤②：ボルグが村を焼けと命じられた過去。ガロウとの対話。
* ③ボス：ボルグ（ガロウが並ぶ）。勝っても見逃す（今の筋どおり）。

### 第3章 本の虫と鉄の花（エルザ。副将グレン）
* 中盤①：ボルグと再戦（強制のラナ戦）。「団の者の家族が王都にいる」とだけ漏らして退く。
* 中盤②：セラの記録＝先王の薬の日付が三日ずれる（今の筋）。ラナが父の死に初めて向き合う夜。
* ③ボス：エルザ（セラが並ぶ）。グレンはエルザの誇りに触れ、少し揺らぐ。

### 第4章 星が震える（黒騎士。副将グレン）
* 中盤①：エルザと再戦。「姉（長姉）が大公の宮にいる」。セラとの葛藤。
* 中盤②：ボルグと三度目。ガロウが「人質ごと取り返す」と言い、ラナが王として約束する（決断の重さ）。
* ③ボス：黒騎士（ランカが並ぶ）。悪魔に怯えるグレンを、ラナが庇う（守る側）。

### 第5章 師の剣（ヘルマン。副将グレン）
* 始まり：ボルグが合流（人質の救出を約束したラナに賭ける）。以後、前哨戦を率いる。
* 中盤①：エルザと最後の戦い。セラの言葉で剣を下ろすが、まだ合流しない（長姉のため）。
* 中盤②：ヘルマンとの「稽古」（強制のラナ戦、ラナ一人）。師を越える。
* ③ボス：ヘルマン（リリィが並ぶ）。剣を託す（今の筋）。グレンは「王の器」を認め始める。

### 第6章 月夜の回廊（大公。副将グレン）
* 始まり：エルザが長姉を連れて合流（王都の内側から門を開ける）。ヘルマンも門の前で兵を率いる。
* 中盤：民の前で、ラナが自分の言葉で語る（石を投げられた広場で）。民心が高いほど、民の声が厚くなる。
* ②：グレンは大公を見限り、民の盾になる（改心）。一騎打ちは「最後の手合わせ」。
* ③ボス：大公・悪魔化の前（g6）→ 悪魔化 → 悪魔の姿（g6b）。隣に全員から選ぶ。
* 結末：大公の処遇（裁く言葉はラナが選ぶ）。選び方の積み重ね（慈悲／厳格）で、民と仲間の言葉が変わる。
