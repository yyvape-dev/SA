# SA
2Dスクロール（アラド戦記型の横スクロール・ハクスラ）。自分用の試作。

## 遊ぶ
`index.html` を開く。GitHub Pages を有効にすると、スマホからURLだけで遊べる。

## 操作
- 移動：矢印キー / WASD　走る：Shift
- 攻撃：J / Space（連打で縦斬り→横薙ぎ）　衝撃波：K　吸引：L　貫通の突き：I　必殺：U
- スマホ：左のパッドと、右のボタン

## 構成
- `index.html`：ゲーム本体（1ファイル）
- `bg.jpg`：背景
- `sprites/`：主人公の連番（待機・歩き・走り・攻撃・横薙ぎ・突き・必殺。攻撃の縦斬りだけ旧0.6倍）

## バージョン
- v6：吸引（L）、必殺・回転斬り（U）を追加。敵は仮の絵。
- v7：待機・歩き・走り・必殺を1.0倍で抜き直し、縁の白・ピンクを除去。キャンバスを高解像度化。
- v8：貫通の突き（I）を追加。通常攻撃の連打で、縦斬り→横薙ぎと続くように。攻撃速度を初期から1.5倍に。縦斬りを新しい絵（1.0倍）に差し替え。
- v9：画面いっぱいの表示、横画面前提の操作UI（左下に移動パッド、右下に大きな攻撃ボタンと、その周りにスキル）。
- v10.1：タッチボタンを画面下へ寄せ、半透明に（押すと不透明）。ボタン・パッドの画像アイコンの差し込み口（`ui/`）。アラド式の横スクロール（戦場ごとにカメラ固定→全滅→GO→前進→部屋移動）。上下カメラの作りを追加（今の部屋は高さ720のため動かない）。
- v10.2：被弾（のけぞり→踏ん張り→立ち直り）と、やられ（のけぞった姿のまま後ろへ倒れる）を追加。静止画4枚（`sprites/dmg_00〜03`）＋コードの動き。攻撃中はのけぞらず、のけぞり中の入力は先行入力になる。
